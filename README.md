# EcoAula Ambiental

Aplicación web educativa desarrollada con HTML, CSS y JavaScript puro.

## Inicio

Abre `index.html` en un navegador moderno.

## Accesos de demostración

- Estudiante: `estudiante@ecoaula.co` / `123456`
- Administrador: `admin@ecoaula.co` / `admin123`

## Funcionalidades

- Registro e inicio de sesión con roles
- Catálogo, búsqueda y filtrado de cursos
- Contenidos interactivos y recursos descargables
- Notas personales guardadas en el navegador
- Cuestionarios con calificación automática
- Seguimiento de progreso
- Certificado imprimible
- Panel administrativo y creación de cursos
- Tema claro y oscuro
- Diseño adaptable a computador, tableta y móvil

Los datos se guardan localmente mediante LocalStorage para que el proyecto funcione sin servidor.
